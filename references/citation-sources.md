## 引用优先级规则（v2.0 强化版）

1. **必引（顶级咨询 ≥5）**：当行业为保险/法律/医疗/教育/金融/汽车/奢侈品/科技时，**麦肯锡 + BCG + 贝恩 + 罗兰贝格 + 德勤 + 奥纬** 至少选 5 家各 1 条
2. **强烈推荐（行业基准 ≥3）**：当涉及代理/经纪/中介/咨询时，**LIMRA + MDRT + IQA + 各行业协会** 至少选 3 条
3. **监管数据 ≥3**：按行业匹配监管源（金融→银保监 / 教育→教育部 / 医疗→卫健委 / 文创→文旅部）
4. **区域数据**：广东/北京/上海/江苏 等省市必有对应监管或统计来源
5. **不使用**：未注明发布方的"行业报告"、营销稿、未注明数据来源的自媒体
6. **行业分库引用**：当 OPC 文档属于教育/法律/医疗/电商/自媒体/金融/文化之一时，**必须从「八、通用行业数据源」对应行业子表中选 ≥3 条**
