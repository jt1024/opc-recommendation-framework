## 🔴 红线级（出现即返工）

### F-01 · 标题版本号缺失或过期

**问题**：标题仍是 v2.0 或更早，未升级到 v3.0。

**检测正则**：
```python
r'^# .+(v[12]\.\d|v3\.0.{0,5}(?!.*043))'
```

**修复**：
```diff
- # 一人数字化转型顾问 · AI 办公 Agent 定制化推荐（v2.0）
+ # 一人数字化转型顾问 · AI 办公 Agent 定制化推荐（v3.0 · 043 质量基线版）
```

### F-02 · 字数声明与实际偏差 > 500

**问题**：开头写"约 8,400 字"但实际 17,000+ 字，或反之。

**检测方法**：
```python
import re
text = open('xxx.md').read()
declared = re.search(r'总字数\*\*[：:]\s*约?\s*([\d,]+)', text)
actual = len(re.findall(r'[一-鿿]', text))
if declared and abs(int(declared.group(1).replace(',', '')) - actual) > 500:
    return "FAIL"
```

**修复**：写完文档后用脚本重新统计中文字符数，更新声明。

### F-03 · 决策卡 ⭐ 数与 D+R+2M 分数不匹配

**问题**：D4 R3 M4 = 15（第三梯队）写了 ⭐⭐⭐⭐。

**对应表（强制）**：

| 总分 | 梯队 | ⭐ 数 |
|---|---|---|
| 18-20 | 第一梯队 | ⭐⭐⭐⭐⭐ |
| 16-17 | 第二梯队 | ⭐⭐⭐⭐ |
| 14-15 | 第三梯队 | ⭐⭐⭐ |
| 12-13 | 第四梯队 | ⭐⭐ |
| ≤ 11 | 第五梯队 | ⭐ |

**检测正则**：
```python
r'D\s*([1-5])\s*R\s*([1-5])\s*M\s*([1-5])\s*=\s*(\d+).{0,200}?(⭐+)'
# 验证 (d + r + 2*m) == total 且 len(⭐) == expected_stars
```

**修复**：根据上表选对应 ⭐ 数。

### F-04 · 第十三章子节顺序错位

**问题**：13.5 / 13.7 / 13.8 内容与模板对应关系错乱。

**正确顺序**（v3.0 模板）：

```
13.5 家庭决策会议 ← (4 项共识 + 4 步沟通 + 应急金 4 级)
13.6 第一步行动 ← (本周 3 件事 + 13.6.1 90 天行动清单)
13.7 给你独特建议 ← (5 句话)
13.8 紧迫提醒 ← (3 条)
13.9 本地 N 目标客户范本 ← (按行业分组 + cold call 话术)
```

**检测正则**：
```python
r'###\s+[\S\s]{0,40}13\.5[\S\s]{0,100}(家庭决策会议|给你独特建议|紧迫提醒)'
# 验证 13.5 后跟的关键词为"家庭决策会议"
```

**修复**：重排章节内容，使 13.5 → 13.9 与模板一一对应。

### F-05 · ★ 专属建议段少于 9 个子节

**问题**：v3.0 升级后 ★ 段必须含 9 个子节，但常被遗漏 90 天清单 / 家庭会议 / 本地客户。

**必含 9 子节清单**（顺序可调）：

1. ✅ 强匹配项（5 条）
2. ⚠️ 风险点（4 条 · 🔴🟡🟢）
3. 💡 推荐路径（4 选 1）
4. 📊 4 方案现金流对比 + 最坏情况兜底
5. 💎 一句话总结
6. 🎯 本周 3 件事
7. 📅 90 天行动清单（W1-W12 + 5 项生死线）  ← 易遗漏
8. 👨‍👩‍👧 家庭决策会议（4 项共识 + 4 步沟通 + 应急金 4 级）  ← 易遗漏
9. 🏢 本地 N 目标客户范本（按行业分组 + cold call 话术）  ← 易遗漏

**检测方法**：
```python
required = ['强匹配项', '风险点', '推荐路径', '4 方案', '一句话总结',
            '本周 3 件事', '90 天行动清单', '家庭决策会议', '本地.*目标客户']
missing = [r for r in required if not re.search(r, text)]
```

### F-08 · 模板占位符残留

**问题**：模板复制后未替换占位符。

**常见占位符**：
- `第 N 梯队` / `第X梯队` / `第 ? 梯队`
- `NNN` / `#NNN`
- `XXX` / `YYY` / `ZZZ`
- `TODO` / `FIXME` / `TBD`
- `[行业名]` / `[用户画像]` 等未替换方括号

**检测正则**：
```python
r'第\s*[N?X]\s*梯队|#[N?X]{2,}|\bTODO\b|\bFIXME\b|\bTBD\b'
```

**修复**：搜替换为具体值。

### F-09 · 引用源未按 A/B/C/D/E 5 组分组

**问题**：第十五章引用源集中堆放，未按查阅场景分组。

**正确分组**：
```
A 组 · 法规与合规类（合同签约 / 红线检查时查阅）
B 组 · 顶级咨询报告与行业研究（5/6/7/13.1 引用时查阅）
C 组 · 区域与官方数据（13.1 强匹配 / 13.9 客户筛选查阅）
D 组 · 工具与平台（5.90 天落地 / 14.2 软技能查阅）
E 组 · 复核规则（对外报告 / 出证 / 高风险项目交付前必看）
```

### F-10 · 业绩基线只有区间值无分布

**问题**：只写"客单价 8-15 万"，缺中位数 + 25/75 分位 + 拒单率。

**检测正则**：
```python
r'客单价.*\d+-\d+\s*万'  # 仅有区间
# 应同时存在
r'中位数.*[\d.]+\s*万'
r'25\s*%?\s*分位|25\s*分位'
r'拒单率'
```

### F-11 · 9.5 法律合规清单少于 8 条

**问题**：合规清单只有 2-3 条，不成体系。

**必含 8 类合规事项**（视行业增删）：
1. 个人信息保护影响评估（PIPA / DPIA）
2. 数据出境安全评估
3. 客户数据本地化处理
4. 委托处理协议（DPA）
5. 生成式 AI 备案
6. 客户商业秘密保护（NDA）
7. 证据 / 报告合规留痕
8. 跨境数据合规

## 🟢 提示级（最佳实践）

### F-13 · 跨章节引用网未建立

**重复出现的同一条信息应明确主出处**：

| 信息 | 主出处 | 引用而非重写处 |
|---|---|---|
| 工具组合 | 四、最终推荐 | 一/三/五/十三 仅引用分数 |
| 数字分布 | 十、业绩基线 + 附录 1 | 十三 仅引用中位数 |
| 客户原话 | 十、案例 | 十三 仅引用一句最强背书 |
| 引用源 | 十五、引用来源汇总 | 其他章仅在文末加"来源：十五章 X 条" |

### F-14 · 决策路径图缺失

**问题**：决策卡后无 4 项硬筛 ASCII 路径图，读者不知下一步。

**修复示例**：
```
═════════════════════════════════════════════════════════════════
 ① 你有 10+ 年 IT 经验？                  → 否：转 OPC 主表
 ② 能接受 6 个月启动期？                  → 否：选兼职试水
 ③ 月供 + 家庭月开支 ≥ 2 万？             → 否：走更轻量诊断
 ④ 本地有可触达客户？                    → 否：先积累远程样板
═════════════════════════════════════════════════════════════════
4 项 ≥ 3 项「是」→ 强烈推荐
3 项「是」    → 推荐兼职试水
2 项「是」    → 不建议全职切入
```
