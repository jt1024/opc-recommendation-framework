# 写作后验收清单（v3.0 · 043 质量基线版）

> 📌 **使用时机**：OPC 文档写完后，**发布前**逐项过一遍。可与 `assets/validate_opc.py` 自动脚本配合使用（脚本覆盖 14 项中的 13 项，本清单补充脚本未覆盖项 + 人工 review 项）。

---

## 🤖 第一关：自动校验（30 秒）

```bash
python assets/validate_opc.py /path/to/xxx.md
```

**期望输出**：
- 总分 ≥ 90 分 → ✅ PASS · 可发布
- 75-89 分 → ⚠️ NEEDS_IMPROVEMENT · 需补强
- < 75 分 → ❌ FAIL · 返工

**任一 P0 项失败 → 必须返工**（按 SKILL.md 第 162-166 行规则）

---

## 📋 第二关：脚本未覆盖项（5 分钟）

脚本覆盖 14 项 + 4 项结构共 18 项检查。以下为脚本未覆盖、需人工 review 的项：

### META-1 · 字数实际值核验

```bash
python -c "
import re
text = open('xxx.md').read()
chinese = len(re.findall(r'[一-鿿]', text))
declared = re.search(r'总字数\*\*[：:]\s*约?\s*([\d,]+)', text)
print(f'实际 {chinese:,} 字，声明 {declared.group(1) if declared else \"未声明\"} 字')
"
```

- [ ] 实际字数在 17,000-22,000 范围
- [ ] 文档开头声明的字数与实际偏差 < 500

### META-2 · 占位符残留扫描

```bash
grep -nE '第\s*[NX?]\s*梯队|#NNN|\bTODO\b|\bFIXME\b|\[行业名\]|\[用户画像\]' xxx.md
```

- [ ] 无占位符残留

### META-3 · 内部链接 / 跳转正确性

- [ ] 文档内的章节引用（如"详见 9.5"）全部能找到对应章节
- [ ] 第十三章子节编号 13.5/13.6/13.7/13.8/13.9 顺序正确
- [ ] 附录 1（评分依据）与主文档 D/R/M 值一致
- [ ] 附录 2（相近场景）的 10 个场景编号真实存在于 OPC 主表

## 📐 第三关：14 项优化逐项过（15 分钟）

### P0-1 读者筛选 · 5 分
- [ ] ✅ 强烈适合（含 4-5 个画像特征）
- [ ] ⚠️ 部分适合（画像偏离/资源不足）
- [ ] ❌ 不适合（缺失关键条件 + 跳转建议）

### P0-2 数字分布 · 12 分
- [ ] 客单价含中位数 + 25 分位 + 75 分位
- [ ] 含拒单率（40-55% 为合理区间）
- [ ] 年营收分布图（3-4 阶段：诊断 / 标准 / 套餐化）
- [ ] 收入分布 ASCII 信息图

### P0-3 本地 20 客户 · 12 分
- [ ] 按行业分组（≥ 3 组）
- [ ] 每组 5 家虚拟但具体的客户（含营收 / 员工 / 委托动机 / 接触路径）
- [ ] cold call 5 步话术
- [ ] 20 家 → 自己名单的转化方法（漏斗）

### P0-4 4 方案现金流 · 12 分
- [ ] 4 方案对比表（A/B/C/D）
- [ ] 每方案：启动时间 / 6 月累计 / 12 月累计 / 储备金需求
- [ ] 最坏情况 6 月 0 收入 + 月度支出明细
- [ ] 5 步应对 + 心理预案

### P0-5 失败案例 · 12 分
- [ ] 2 个失败案例（启动失败 + 项目失败）
- [ ] 每个失败案例：背景 / 根因 5 条 / 退出成本 / 教训 5 条
- [ ] 退出机制 4-6 步（D1/D7/D14/D30/D60/D90）
- [ ] 失败 vs 成功对比表

### P1-6 客户原话 · 5 分
- [ ] 每个成功案例 ≥ 3 条客户原话 / 同行访谈
- [ ] 直接引语（带引号）
- [ ] 来源明确（客户 A / 同行 B）

### P1-7 工具上手日记 · 5 分
- [ ] 14.2.E 工具上手真实日记节
- [ ] ≥ 3 个核心工具
- [ ] 每个工具含 D1/D7/D14/D30
- [ ] 含学习曲线（0% → 95%）

### P1-8 法律合规 · 5 分
- [ ] 9.5 节存在
- [ ] ≥ 8 条具体合规事项（个保法 / 数据出境 / DPA / 商业秘密 / 生成式 AI 备案 等）
- [ ] 9.5.1 合规红线检查清单（≥ 8 项勾选项）
- [ ] 9.5.2 合规应急流程（4-6 触发场景）

### P1-9 家庭决策会议 · 5 分
- [ ] 13.5 节存在
- [ ] 4 项硬共识表
- [ ] 4 步沟通脚本（第一步 → 第四步）
- [ ] 应急金 4 级（🟢/🟡/🟠/🔴）
- [ ] 配偶质疑 + 应对话术表

### P1-10 评分依据 · 5 分
- [ ] 附录 1 存在
- [ ] D/R/M 每个数值 4-5 个数据点 + 来源
- [ ] 每个数值的评分逻辑说明
- [ ] 综合分验证公式（D + R + 2M = N）

### P2-11 90 天清单 · 3.75 分
- [ ] 13.6.1 或 ★ 段含 90 天行动清单
- [ ] W1-W12 按月拆解（3 个月 + M4-6 拓展期）
- [ ] 5 项生死线总览

### P2-12 引用源分组 · 3.75 分
- [ ] 第十五章独立成章
- [ ] A 法规 / B 报告 / C 区域 / D 工具 / E 复核 五组齐全
- [ ] 每条含"何时查阅"列

### P2-13 ASCII 信息图 · 3.75 分
- [ ] 决策路径图（4 项硬筛）
- [ ] 收入分布图
- [ ] 至少 2 个 ASCII 信息图

### P2-14 相近场景跳转 · 3.75 分
- [ ] 附录 2 存在
- [ ] 10 个相邻场景（按相似度排序）
- [ ] 跳转决策树
- [ ] 跳转操作步骤

## 🔬 第四关：人工 review（10 分钟）

### 内容质量
- [ ] **行业基线引用**：至少 7 个章节有引用块（法规 / 报告 / 区域 / 工具）
- [ ] **数据真实可查**：每个数字有来源 / 年份 / 样本
- [ ] **数字分布合理**：客单价 / 月收入 / 年营收不在无依据下断言
- [ ] **不复制 043 原文**：行业数据 / 客户 / 案例为本场景重新生成

### 文案质量
- [ ] **每章有 TLDR 4 行**：📌 1 句话 + 🎯 读完你能做什么 + ⚡ 紧急程度 + ⏱️ 阅读耗时（含字数）
- [ ] **跨章引用网**：每条信息有唯一主出处
- [ ] **占位符已替换**：搜替换完成

### 法律风险
- [ ] **不出具法定意见**（如保收益 / 出审计报告）
- [ ] **DPA / NDA 模板已就位**（边界文件 3 件套）
- [ ] **客户商业秘密保护条款**已写入边界文件
