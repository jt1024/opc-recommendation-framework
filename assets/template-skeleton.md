```markdown
## 附录 0：OPC 综合分 · D+R+2M 模型说明

### 公式
```
OPC 综合分 = D + R + 2M
满分 20 分（4 维度：1 个 D + 1 个 R + 1 个 M × 2 加权）
```

### 4 维度定义
| 字母 | 含义 | 满分 | 说明 |
|---|---|---|---|
| **D** | Demand 需求度 / 市场体量 | 5 | 客户基数、付费意愿、复购频次、区域市场容量 |
| **R** | Risk 风险系数（高分=低风险）| 5 | 合规难度、获客波动、回款风险、行业周期性 |
| **M** | Maturity 行业成熟度 | 5 | 行业基础设施完整度（工具/SOP/服务链/客群认知）；**双倍权重** |

### 加权机制
- M 行业成熟度双倍加权：M × 2 = 占比 10/20（50%）
- D 与 R 各占 5/20（25% each）

### 梯队划分
| 总分 | 梯队 | ⭐ |
|---|---|---|
| 18-20 | 第一梯队 | ⭐⭐⭐⭐⭐ |
| 16-17 | 第二梯队 | ⭐⭐⭐⭐ |
| 14-15 | 第三梯队 | ⭐⭐⭐ |
| 12-13 | 第四梯队 | ⭐⭐ |
| ≤ 11 | 第五梯队 | ⭐ |

### 本场景实例
D[N] R[N] M[N] = [N]/20 · 第 [N] 梯队
验证：D + R + 2M = N + N + N×2 = N/20
```
